## Operating model

* Excel = master tracker / single source of truth
* Streamlit = dashboard, automation, briefing, email templates and Regional Office reporting layer

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app can use the default CSV demo data or read the Excel master file from the sidebar upload.
